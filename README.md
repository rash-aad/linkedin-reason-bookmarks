# LinkedIn Reason Bookmarks

Remember why you sent someone a LinkedIn connection request.

You send a request with a reason in mind. They accept weeks later, and you've forgotten why. This Chrome extension lets you pin a note to any LinkedIn profile, and shows it again next time you open that profile.

## Features

- **"+ Note why" button** on every LinkedIn profile
- **Your note shows up** whenever you revisit that profile
- **Bookmarks page** (click the extension icon) listing everyone you've marked, with search
- **Private:** notes are stored only in your browser (`chrome.storage.local`). No account, no server, no analytics.

## Install

1. Download this repo: **Code → Download ZIP**, then unzip it (or `git clone` it).
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select the unzipped folder.
5. Open any LinkedIn profile, and the button appears in the bottom-right.

## Notes

- Notes don't sync between computers, and uninstalling the extension deletes them.
- Works in Chrome and other Chromium browsers (Edge, Brave, Arc).
